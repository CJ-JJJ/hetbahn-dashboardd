전체 실적 데이터 불러오기

엑셀의 표 전체(헤더 포함)를 복사해 아래에 붙여넣으세요. 열 이름: 구분 / 조직 / TEAM / 경로 / 본부 / 소본점 / 소본점명 / TG / 실적 / 달성률

엑셀에서 표를 선택 → 복사 → 아래 칸을 길게 눌러 붙여넣기 → ‘데이터 적용’. 전체 자료를 넣으면 현재 미리보기 데이터는 교체됩니다. CSV/TSV 파일도 선택할 수 있습니다.
